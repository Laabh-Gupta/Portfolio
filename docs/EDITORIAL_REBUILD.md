## Interaction and engineering

`useQueryState` validates shareable states for the workflow, gallery filter/project, skills, architecture, and personalization loop. Defaults hydrate against prerendered markup before client URL selection. Changing a control keeps the current reading position; opening its URL lands at the appropriate section. Project details activate on click/Enter rather than changing simply because a pointer or keyboard focus passes across a row.

Scroll restoration sits inside the route’s Suspense boundary, so it waits for committed route content. Browser Back restores prior scroll positions and explorer selections. Anchor placement waits for self-hosted fonts; lazy routes can finish before the target is resolved. The case study has semantic chapter links.

There is one `FlowField` at app-shell level. It survives route navigation, uses chapter profiles, and remains behind interactive content. Fine-pointer animation settles; touch and reduced-motion use a composed still. Pointer events never belong to the canvas. The identity’s separate WebGL canvas is solely for the LG object, not a duplicate background.

The LG uses custom beveled paths, ceramic/silver/graphite materials and procedural studio lighting. A matching SVG appears immediately. WebGL loads only for eligible wide fine-pointer displays, stops drawing at rest/offscreen, and releases resources. Failure, context loss, touch, and reduced motion retain the complete static composition. Existing tests measure actual draw-call inactivity rather than only checking CSS classes.
